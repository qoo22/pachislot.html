# Super Revolution Slot

ブラウザだけで動く 1 ファイル完結のパチスロ風ウェブゲームです。
HTML / CSS / JavaScript + Web Audio API のみで作られており、外部ライブラリは使っていません。

## 遊び方

1. ブラウザで `pachislot.html` (または `index.html`) を開く
2. クレジット 500 枚スタート、BET 1〜20 まで選択可能
3. SPIN ボタンを押してリールを回す
4. 数字 3 つ揃いで大当り

ゲームは PC・iPhone・Android のブラウザで動作します。
スマホでもタッチ操作・自動回転に対応。

## 主な機能

- **3 段階モード**: 通常 / 確率変動 (確変) / 超革命モード
- **リーチ信頼度**: シングル / ダブル / トリプル の 3 段階表示
- **激熱演出**: 「7」テンパイは信頼度ほぼ 100%
- **昇格演出**: 通常時の偶数当選が稀に奇数昇格 (確変直行)
- **引き戻し**: 確変終了後 50 回転以内に当選すると V マーク +1 で確変復活
- **超革命モード**: 1/2 抽選を 4 連続外すまでループ。連チャン数で BGM が切替
- **超革命 BGM (公有楽曲のシンセ合成)**:
  - 0-9 連: ベートーヴェン 第九 第 4 楽章 (歓喜の歌)
  - 10-19 連: パッヘルベル カノン in D
  - 20-29 連: アメージング・グレイス
  - 30-39 連: ベートーヴェン 運命 第 1 楽章
  - 40-49 連: ベートーヴェン 第九 - 歓喜の歌 (荘厳ピアノ編)
  - 50-59 連: チャイコフスキー くるみ割り人形 - 金平糖の精の踊り
  - 60-69 連: モーツァルト アイネクライネナハトムジーク
  - 70 連目以降は 0-69 のサイクルでループ
- **バトル演出**: リーチ時にバトル発生、絶望からの覚醒・お助けキャラ参戦・逆転勝利
- **復活当選**: 超革命中に稀にハズレから復活する専用カットイン
- **GOGO! ランプ先告知**: 当選確定時 35% で点灯。確変中は青、超革命中は紫ネオン
- **ペットシステム**: クレジットでペット (ハムスター/ねこ/いぬ/うさぎ/パンダ/きつね) を購入可能。同時に画面に出せるのは 1 匹。タップで鳴き声を吹き出し表示
- **ランキング**: 最高連チャン数、確変記録、超革命記録、当選履歴 (最新 20 件) を端末ごとに保存
- **AUTO 機能**: AUTO ボタンで自動回転。確変・超革命中は自動で AUTO ON
- **リセット機能**: 全記録消去 + クレジット 500 枚復活 (二段階確認付き)

## 技術仕様

- 単一 HTML ファイル (`pachislot.html`) で完結 — 外部依存なし
- Web Audio API でリアルタイム音声合成 (ピアノ倍音 + リバーブ)
- localStorage で記録・クレジット・ペット情報を端末ごとに永続保存
- レスポンシブ対応 (PC / タブレット / スマートフォン)
- 完全に静的サイト — GitHub Pages や任意のウェブサーバで動作
